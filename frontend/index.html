📖 Panduan Script Pandas

Di dalam node ini, data dari node sebelumnya secara otomatis ditampung dalam variabel df (Pandas DataFrame).

  • Melihat Data: df.head()
  • Membuat Kolom Baru: df['total'] = df['harga'] * df['qty']
  • Filter Baris (Multi Kondisi): Gunakan & (AND) atau | (OR) dalam kurung.
    df = df[(df['segmen'] == 'UMKM') & (df['total_harga'] > 1000000)]
  • Select Distinct: Menghapus baris duplikat berdasarkan kolom tertentu.
    df = df.drop_duplicates(subset=['kolom_id'])
  • Rename Kolom: Mengubah nama kolom lama menjadi nama baru.
    df = df.rename(columns={'nama_lama': 'nama_baru', 'harga_lama': 'harga_baru'})
  • Format Date & Number: Mengubah tampilan format teks.
    Date (ke String DD-MM-YYYY): df['tanggal'] = pd.to_datetime(df['tanggal']).dt.strftime('%d-%m-%Y')
    Number (Pemisah ribuan): df['harga'] = df['harga'].apply(lambda x: "{:,.0f}".format(x))
  • Filter / Select Kolom: Mempertahankan kolom tertentu saja.
    df = df[['kolom1', 'kolom2', 'kolom3']]
  • Agregasi Multi-Kolom & Multi-Fungsi:
    df = df.groupby(['kategori', 'wilayah']).agg({'qty': 'sum', 'id': 'count', 'nama': lambda x: ', '.join(x.dropna().astype(str))}).reset_index()
  • Sumifs / Countifs (Kondisional):
    Sumif: total = df.loc[df['status'] == 'Aktif', 'harga'].sum()
    Countif: jumlah = df.loc[(df['status'] == 'Aktif') & (df['qty'] > 10), 'id'].count()
  • Merge (Join Tabel):
    df = pd.merge(df, df_lain, on='kolom_kunci', how='left')
  • Pivot Table (Baris ke Kolom):
    df = pd.pivot_table(df, values='total_harga', index='tanggal', columns='kategori', aggfunc='sum').reset_index()
  • Melt (Kolom ke Baris / Unpivot):
    df = pd.melt(df, id_vars=['tanggal'], value_vars=['produk_A', 'produk_B'], var_name='nama_produk', value_name='penjualan')
Penting: Modifikasi harus disimpan kembali ke variabel df. Gunakan .reset_index() setelah group atau pivot agar format tabel tetap rata untuk diteruskan ke node selanjutnya.

📊 Panduan Custom Format Excel (`formatConfig`)

Masukkan konfigurasi dengan format nama_kolom:format yang dipisahkan koma pada input Format Kolom di inspector.

Contoh pengisian: tanggal_lahir:YYYY-MM-DD, penghasilan:Rp #,##0, diskon:0.00%

Daftar Referensi Format:

Kategori Format String Contoh Hasil Keterangan
Tanggal YYYY-MM-DD 2026-11-14 Standar internasional
Tanggal DD/MM/YYYY 14/11/2026 Format Indonesia
Mata Uang "Rp" #,##0 Rp 1.500.000 Rupiah tanpa desimal
Mata Uang "Rp" #,##0.00 Rp 1.500.000,00 Rupiah dengan 2 desimal
Angka #,##0 123,456 Pemisah ribuan
Persentase 0.00% 12.50% Format persen desimal
Teks Murni @ 12345 Memaksa format string
Tips: Jika kolom pengaturan format dikosongkan, Excel akan menggunakan format bawaan (default) dari data tabel secara mentah tanpa modifikasi tambahan.
